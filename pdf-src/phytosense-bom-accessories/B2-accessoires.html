Accessories and tooling

What is not on the board, and without which the board is of no use: enclosure, cables, electrodes, power supply, test instruments.

Three remarks that save time

The USB-C cable has to carry data. Many cables sold with chargers contain only the power conductors. A board that has power but is invisible to the system is almost always a cable problem.

The external battery is the best accessory of the lot. Twenty-five euros, and the last coupling path to the mains disappears. On long recordings the gain is measurable.

Isopropyl alcohol is not a finishing product. It is a manufacturing step: a flux residue between the input and the guard conducts quite enough to ruin a very high-impedance measurement.
