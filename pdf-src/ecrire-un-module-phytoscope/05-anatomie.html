2. Anatomie d'un module

Un module est un dossier contenant un fichier module.py, qui déclare une classe héritant de Module. Tout le reste est facultatif.

Le manifeste, seul élément obligatoire

from phytoscope.api import Capacite, Manifeste, Module

class MonModule(Module):
    MANIFESTE = Manifeste(
        nom="mon-module",           # a-z, 0-9, tirets — l'identifiant
        titre="Mon module",         # ce que l'utilisateur lit
        version="1.0.0",
        api="1.0",                  # la version d'interface visée
        description="Ce que fait ce module.",
        auteur="Votre nom",
        licence="MIT",
        capacites=(Capacite.ANALYSEUR,),
    )

Le manifeste est lu sans exécuter votre code

Le logiciel analyse syntaxiquement module.py pour en extraire le manifeste, avant de l'importer. C'est ce qui lui permet de lister les modules présents, d'en désactiver un et de refuser celui qui vise une interface inconnue — sans avoir à exécuter du code pour savoir s'il faut l'exécuter.

Conséquence pratique : écrivez des valeurs littérales. Une valeur calculée — version=lire_version() — ne sera pas lue, et le défaut s'appliquera. Seules les constantes de Capacite font exception, parce qu'elles appartiennent au contrat.

Le cycle de vie

  1. __init__(contexte) — vous recevez le contexte. Ne faites rien de long ici : c'est appelé au démarrage, pour tous les modules, l'un après l'autre.
  2. installer() — une fois, après le chargement de tous les modules. C'est ici qu'on s'abonne et qu'on prépare ses fichiers.
  3. vos capacités sont appelées pendant la séance, à la demande.
  4. arreter() — une fois, à la fermeture. Fermez ce que vous avez ouvert ; les abonnements sont retirés pour vous.

Vos réglages

def reglages_par_defaut(self):
    return {"seuil_uv": 8.0, "montrer_le_detail": True}

# plus tard, dans une capacité :
seuil = contexte.reglages.get("seuil_uv", 8.0)

Le logiciel les conserve sous le nom de votre module et vous les rend au démarrage suivant. N'écrivez jamais vous-même dans le fichier de réglages du logiciel : il ne vous appartient pas, et sa forme peut changer.
